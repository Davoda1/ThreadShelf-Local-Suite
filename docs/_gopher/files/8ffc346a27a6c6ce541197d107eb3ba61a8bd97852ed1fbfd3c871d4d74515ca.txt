# ThreadShelf Local Alternative 1.0.0

Alternative is an independent desktop workspace for browsing and reading a live ThreadShelf server. It combines a conversation shelf, full-thread reading, prompt outline, server search, pins and saved searches. The warm paper/teal visual design offers System, Light and Dark appearance modes.

It reads the server through supported read APIs. It does not import provider exports, ingest into the server, reindex conversations, edit archived messages or create Reader’s Local database. Use [Local Reader](../Reader/index.md) for a persistent offline archive and [Local Analytics](../Analytics/index.md) for captured statistical analysis.

## A first successful session

Start your server, connect Alternative, choose a nonempty collection and open a conversation. Check the title and message content. Run a short **Text** query, then return to the whole thread from a matching passage. Pin the thread, close it and reopen it from **Pins**. Finally set your preferred reading size and color mode in **Reading & appearance**.

A pin or recent-history entry is a saved reference. The server must still supply the conversation when you reopen it. Use explicit Markdown export when you need an independent copy of one conversation.
