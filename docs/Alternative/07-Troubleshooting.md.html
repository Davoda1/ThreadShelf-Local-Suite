Alternative: troubleshooting and shortcuts

Resolve the source before the symptom

Check whether you are in Demo workspace or connected to a real server. Confirm the server address, current collection, selected navigation view, query and role filter. Pins, Recent and Library intentionally show different populations.

SymptomChecks and next action
Cannot connectServer is running; address is the final HTTP(S) base URL; correct port/prefix; reachable network; Host/Origin rules and firewall permit it
Browser server works but app does notCheck interactive login, proxy authentication or redirects; this release does not implement those login flows
No conversationsChoose a nonempty collection or All collections; clear query/filters; confirm the server contains indexed data
Search has several hits with one titleSearch returns passages; open them to inspect their common conversation
Search ends at 50Read the bounded-result notice; use the verified server integration if complete pagination is needed
A later search page failsSearch snapshot may have expired or the server restarted; rerun from the first page
Semantic search failsInspect the server’s embedding/model setup and error; desktop appearance does not configure server models
Pin or Recent entry cannot reopenThe reference remains local but the referenced server/source conversation must still exist and be reachable
Rich image/widget is absentRequired metadata or media may not exist in the export/server normalization; inspect the source and fallback text
Diagram cannot renderInspect original source; automatic repairs cover only known deterministic cases
Saved preferences could not be loadedChanges remain session-only and saves are blocked; close the app, preserve the profile, restore a good backup or move aside only this profile, then restart
Preference does not survive restart after a successful loadCheck save-error notification, profile permissions and available storage; preserve the existing state file
Startup cover remains visibleRead the error, correct it and choose Retry startup

Keyboard reference

ShortcutAction
Ctrl+KFocus/select library search and reveal the shelf
Ctrl+FFind within the open conversation
Enter in FindNext match
Shift+Enter in FindPrevious match
Ctrl+Shift+FToggle focus mode
Ctrl+\Show or hide the conversation shelf
EscClose the active relevant panel or leave focus mode

Keyboard actions do not override a currently open modal dialog. Esc closes the relevant active UI in context; it is not a server-disconnect or data-delete command.

A useful issue report

Report the app version 1.0.0, operating system, package filename, source type, steps, expected result, actual result and exact nonsecret error. State whether it happens in the native desktop app or standalone demo. Supply a minimal synthetic conversation if that reproduces the issue. Review screenshots and copied URLs before posting them.

Use the suite issue tracker. Issues in the unmodified server itself belong to the upstream ThreadShelf project; explain whether the search patch is applied.
