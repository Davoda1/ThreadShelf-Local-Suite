# Gopher HTTP 3.0.0 publisher

This directory contains the supplied original Gopher HTTP 3.0.0 publisher used
to rebuild the ThreadShelf Local Suite manual. The executable PHP source,
editable source modules, bundled local assets, content-format documentation and
packaging script are retained. Original demonstration content, preview output,
archives and unrelated application binaries are excluded.

The publisher's license is preserved in `LICENSE`. The version is independent
of the Suite's public GUI versions. See `../README.md` for the manual build.
