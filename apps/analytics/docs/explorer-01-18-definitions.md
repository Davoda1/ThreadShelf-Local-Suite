# Explorer measurement definitions 01–18

These are new definitions; `explorer-a` does not change the legacy 1.0.0 metric identifiers, regex content analysis, or floor-index percentile definitions. Calculation version is `2.0.0-explorer-a-v1`. Full-text analysis version is `2.0.0-marked-r7-v2`; owned-index schema/fingerprint validation belongs to the capture/index layer.

Every descriptor supplies the variable, observation unit, applied scope, eligible/available/unavailable population, original date basis, timezone/precision, branch/version policy, membership perspective, source representation, reliability, version, numerical table, state/reason, and evidence selection rule. Zero denominators produce `null`. A genuinely observed empty string has length zero; missing text, redacted content, invalid metadata, and missing full-text indexes do not become zero measurements.

| Family | Exact numerical tables and eligibility |
| --- | --- |
| 01 Length histogram/ECDF | Separate user, final response, observed original trace, and summary-only populations. Segment lens or supported logical-message lens. Code points are counted by Unicode iteration. Histogram bins are half-open; ECDF rows supply threshold, count at threshold, cumulative count, denominator and fraction. Partial logical selections are counted explicitly. |
| 02 Length small multiples/boxes | Same selected category grouped by provider, model or observed month. Count, minimum, Q1, median, Q3, maximum and mean. Quantiles use Hyndman–Fan type 7 (R7), frequency weighted without expanding arrays. A set of fewer than five observations is marked as a small sample. |
| 03 Conversation concentration | Neutral conversation labels, observed contribution, rank, cumulative contribution/share and top 1/5/10% contribution. Top fractions use `ceil(N × fraction)` with at least one conversation when N is positive. Distinct conversation ranks remain distinct; membership perspective weights their contributions. |
| 04 Code size | Retained parser-recognized fenced bodies grouped by exact declaration's first whitespace-delimited word, with explicit Unspecified. Raw declaration retained separately; aliases require an explicit map. Body code points or retained lines, R7 summaries, and closed/unclosed counts. CommonMark list/quote container prefixes are removed from token body, rather than counted as code. |
| 05 Exact prompt spectrum | Complete trustworthy logical prompts, or explicit segment fallback when grouping is unavailable. Ordered user segment text joins with two newlines, normalizes NFC, collapses Unicode whitespace and trims, case sensitively. SHA-256 keys are wording equality keys, not request identities. Distinct observed prompt identities remain distinct. Partial logical prompts cannot borrow a whole-prompt index hash. Neutral group labels, frequency spectrum, distinct conversations/models and membership-weighted frequency are separate. |
| 06 Attachment bytes/dimensions | Scoped metadata dedupe by conversation/native attachment ID; otherwise object/source descriptor identity. True zero bytes is available. Width/height require finite positive numbers; dimensions do not imply accessible media. Exact byte histogram/ECDF, width×height counts and aspect-ratio bins. |
| 07 Weekday/hour | 168 exact cells in selected IANA timezone. Segment, stored-object or supported-logical unit. An object/message counts once across thinking/final categories; the first retained original segment before filtering is the timestamp anchor for that object/message. Clock precision is mandatory; epoch zero is valid and day-only dates are excluded. |
| 08 Seasonality | Month×year counts, within-year shares, and rate per actual calendar day. An explicitly bounded date selection gives the denominator; otherwise use first through last retained observed dated day. Rates include real leap days and partial-month clipping. No unexported events are inferred. |
| 09 Streak/gaps | Individual active-day runs plus exact run-length distribution. Gaps mean intervening empty calendar days, not calendar distance. First/last archive runs are censored. Segment-date coverage is separate from unweighted calendar observations. |
| 10 Continuation | Cohort is the week of first retained dated message before record filtering, within branch policy. Later offsets require retained archive coverage through the entire offset week before entering the denominator for that offset. Counts/fractions and insufficient-followup counts are explicit. This is observed conversation continuation, not user retention/churn. |
| 11 Response position | Supported original selected path or verified native source sequence establishes reply ordinals before filtering. Removed replies leave visible ordinal gaps. Observed reply code-point R7 bands, sample n, partial-message count and code-body share. This does not measure learning, fatigue or quality. |
| 12 Recorded intervals | Recorded parent adjacency or verified original source order is established before filtering. Both objects must remain selected and have clock-precision original timestamp anchors. Fixed millisecond bins, ties, reversed observations and filtered/precision gaps are separate. These are recorded timestamp gaps, never latency, TTFT or execution duration. |
| 13 Prompt×reply volume | Conversation lens requires observed user and final-response categories; paired lens additionally requires recorded parent ancestry to a user object or verified shared turn association. Array order and a logical ID alone do not establish pairing. Fixed two-dimensional bins include exact weighted counts and x/y sums. |
| 14 Trace×response | Original observed trace versus final response within a conversation or same recorded object. Summary-only population is separate. Fixed density cells; ratio of weighted sums is separate from R7 quantiles of per-unit ratios. Nonpositive response denominator yields unavailable ratios. No hidden reasoning is inferred. |
| 15 Model feature prevalence | Supported logical final replies; numerator/denominator, prevalence and occurrences are separate. Parsed fence/link/table presence counts once per reply. Attachment metadata has an independent denominator, requiring observed metadata or explicitly complete attachment coverage; absent metadata is unknown. |
| 16 Co-occurrence | Separate model and declared-language presence matrices, using conversation or supported logical-reply sets. Repeated blocks do not multiply support. Exact joint, union and Jaccard. Top axes by weighted presence; labels beyond the requested bound enter a visibly labelled Other presence set. Full population/label summary and every grouped cell remain exact. |
| 17 Reference channels/domains | Textual links, structured references, unlinked citation markers and unlinked reference entries stay separate. Only HTTP(S) URLs enter domain cells. URL normalization lowercases host, drops fragment/default port/credentials, and retains path/query internally. Cross-channel identical URLs dedupe within scoped source object. Complete domain concentration ranking, model/domain counts, distinct-domain diversity and explicitly bounded grouped co-occurrence. No URLs are fetched. |
| 18 Markdown profile | `marked` CommonMark/GFM lexer analyzes complete owned text. Heading, list/item, quote, table, inline/fenced/indented code, link/image, thematic-break and paragraph occurrences and segment presence are separate. This parser-derived definition does not overwrite legacy regex results. |

Length edges: `0, 1, 10, 50, 100, 250, 500, 1000, 2500, 5000, 10000, 25000, 50000, 100000, 250000, 1000000, +∞`. Byte edges: `0, 1, 1024, 16384, 262144, 1048576, 16777216, 268435456, 4294967296, +∞`. The exported final upper bound is `null` with `upperUnbounded:true`, preserving exact machine-readable meaning without invalid JSON infinities.

R7 computes `h=(N−1)p`, interpolating between the observations at `floor(h)` and `ceil(h)`. Membership-weighted observations behave as integer frequency repetitions, without allocating expanded arrays. It is deliberately a new definition rather than relabelling old percentiles.

Full-text indexes are produced before any GUI excerpts. An excerpt without a valid new index produces rebuild-needed/unavailable text analysis, rather than a short text measurement. Individual parser input is bounded at 16 MiB and 500,000 tokens. A bound or parser failure makes parser structures unavailable with an explicit reason; complete code-point/fence fallback observations remain independent. No rendering, code execution, media access or network operation occurs during analysis.

Matrix axes default to 40 and are bounded to 100. Remaining labels use a collision-safe explicit Other axis; presence and Jaccard for that axis concern the union of omitted labels. Full domain rankings remain complete. The exact table documents original/retained/Other label counts. This is aggregation, not silently dropped observations.

Evidence lives in a worker-owned index. ECDFs, cumulative concentration and matrices resolve their contributing segment IDs lazily, avoiding cumulative quadratic ID arrays. Numerical tables contain scalar evidence keys, not archive text or ID lists. An ECDF selects observations at or below the ECDF threshold; cumulative concentration selects contributors through that rank, while `rankEvidenceKey` identifies the individual contribution. Denominator populations are stated in the numerical table/contract. Scoped explicit aliases choose the same newest retained producer as shared filtering, so aliasing cannot connect newly adjacent visible records.

Private prompt wording, titles, filenames and full URLs are absent from these aggregate tables. Literal code declarations and domain dimensions are marked as private columns, requiring the report's deliberate label-inclusion choice. Original source text and hashes are not changed by parsing.

`test/explorer-a.test.mjs` uses independent synthetic numerical expectations for every family, including null-versus-zero, Unicode, R7 interpolation, leap-year rates, epoch zero, hourly grouping, exact repeats, attachment dedupe, parent-only pairing, filtered gaps, aliases, parsed nested fences, URL channel reconciliation, full-text indexes and lazy evidence. These tests do not claim real-provider completeness or native-platform execution.
