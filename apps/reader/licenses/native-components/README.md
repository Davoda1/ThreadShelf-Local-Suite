# Native dependency copyright and license notices

These original notices accompany the sharp/libvips dependencies distributed with ThreadShelf Local Reader. Each component retains the original terms. The application's MIT license does not replace them.

| --- | --- |

| Additional upstream license texts/declarations | [Original notices](supplemental.md) |

The [provenance manifest](manifest.json) records each original filename, source and SHA-256 hash. Identical texts share a file named by the content hash; their bytes and copyright statements are unchanged. This keeps portable Windows paths short.

The inventory conservatively retains notices from source-only tests, build tools and conditional targets as well as runtime code. A few historical crates publish an MIT declaration and author metadata without a separate license or copyright file; their exact declarations and the provenance of that finding are retained. No missing copyright statement has been invented.

Source archives, patches and build recipes are available in the separate [native-source companion](https://github.com/Davoda1/ThreadShelf-Local-Suite/releases/download/v1.0.0/ThreadShelf-Local-Suite-1.0.0-Native-Sources.tar.gz). See [source and rebuild instructions](../SOURCE-AND-REBUILD.md) for the covered versions, replacement paths and upstream provenance limits. The companion includes complete original source archives with additional per-file notices.
