# Alternative 1.0.0 verification

Public release preparation: 21 October 2026.

## Executed checks

- The existing server-adapter and isolated state suite passed **21 tests**, with zero failures or skips. It covers exact multi-conversation identity, paged search, expiry, stock-server limits, URL/response restrictions, cancellation and independent preference storage. Two release-audit regressions additionally verify that corrupt or oversized settings cannot be overwritten by autosave or close-flush attempts, and that explicit closed-profile recovery permits normal saving again.
- Application entry-point syntax and Python build-script compilation passed.
- The final publication audit also passed the content-rendering, syntax-highlighting, complete offline-demo, demo-guide and startup browser suites using an installed headless Chromium runtime. These cover rich rendering, safe links and copying, all 13 demonstration conversations, role/collection searches, light/dark and minimum-window layouts, offline route boundaries, and the persistent session-only recovery warning. Browser results are distinct from native OS acceptance checks.
- The highlighter and Mermaid repair adapter regenerate byte-for-byte from their included source.
- The Windows portable ZIP passed CRC integrity, root-native-EXE and public-version checks.
- The initial package validator checked all three native package formats and compared **32 application files per package** with the then-current source. Final CI repeats source parity and official runtime inventory/hash checks after the additional source-access notices and runtime update.
- Linux portable and Debian entry points resolve directly to native ELF executables. Debian ownership, executable modes, the 04755 sandbox helper and desktop entry passed inspection. No launcher scripts or build-only tools are present in runtime packages.
- The exact renderer builds into a standalone offline HTML demo. The demo fixtures are synthetic.
- Manual-capture native Linux Electron 44.4.5 checks passed through the real app: 13 demo conversations, light and dark themes, public version 1.0.0 in Settings, text search with the two expected results, opening the matching conversation, and the server connection dialog. The five manual PNGs were visually inspected. No renderer exceptions or HTTP(S) requests occurred. The harness used an isolated temporary profile, Xvfb, and test-only sandbox/single-instance accommodations; production entry points were unchanged.

The historical packaging and screenshot results are in `verification/package-validation.json` and `verification/native-capture.json`. Final package reports are generated by the successful **Build desktop packages** workflow.

## Toolchain

The final release pins Node.js 24.19.0 LTS, npm 11.9.0 and Electron 44.9.1. The manual screenshots above were captured earlier with Electron 44.4.5; their recorded runtime is preserved. Official runtime ZIP digests are pinned in `scripts/build.py`. Application package version is 1.0.0; the Windows numeric file/product version is 1.0.0.0. Historical development revision numbers are absent from public application metadata.

## Limits

Final CI checks native Windows and Linux runtime identity by launching each staged executable in Electron’s Node mode; this does not test Windows GUI interaction. Linux installation and sandbox operation vary by distribution and remain target-system checks. The native Linux capture exercised demo workflows, not connection to a live private archive. No previous private development evidence is presented as a fresh test of this release.
