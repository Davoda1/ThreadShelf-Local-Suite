# ThreadShelf Local Suite 1.4.4 verification record

## Scope

Reader and Alternative add bounded inline HTML/CSS formatting, source-preserving VeniceAI citation badges and explicitly selected native HTML previews for eligible complete HTML5 documents. Native previews are temporary, sandboxed and separate from the application, with no Node.js/application bridge, restricted permissions/navigation/downloads and a bounded public-HTTPS resource broker. Code, math, copying, existing SVG rendering and ordinary image controls retain their distinct behavior.

Preservation checks cover attachments, substantive reasoning, divergent answered histories, survivor/source history, bookmarks and stale-review rejection. Optional prompt-only cleanup for other providers starts disabled. The existing public image restrictions, application identities, profile paths, archive schemas and ONNX privacy controls remain intact. Additional immutable crash-reporting guards and the model-library request-header privacy patch suppress unwanted metadata/reporting without changing explicit provider requests.

All three applications report 1.4.4. Analytics has no functional or dependency changes; its product version, package filenames and current documentation are aligned. The Alternative notice version is corrected. Original suite licensing remains MIT, Copyright (c) 2026 davoda1; imported parse5 and entities source retains its correct MIT and BSD-2-Clause notices.
